# market-data-feed

Бесплатный облачный сборщик рыночных данных для ежедневной сводки в Claude.

GitHub Actions два раза в сутки тянет дневные свечи по России, США и криптовалютам,
считает индикаторы в pandas и коммитит результат в `data/market_snapshot.json`.
Claude потом читает готовый файл одной командой — ноутбук для этого не нужен.

## Зачем

Из облачной песочницы Claude нет прямого доступа к биржевым API: сеть контейнера
работает по белому списку, а `WebFetch` к API-эндпоинтам блокируется их robots.txt.
Зато `raw.githubusercontent.com` из песочницы доступен. Этот репозиторий и есть мост.

Побочная выгода важнее основной: RSI, MACD и скользящие здесь **считаются** по
фактическим свечам, а не пересказываются моделью со стороннего сайта.

## Установка

1. Создайте **публичный** репозиторий (для публичных репозиториев минуты Actions бесплатны
   и безлимитны; приватным дают 2000 минут в месяц — этой задаче хватит и их).
2. Положите в корень: `fetch_market_data.py`, `requirements.txt`.
3. Положите workflow в `.github/workflows/market-data.yml`.
4. Settings → Actions → General → Workflow permissions → **Read and write permissions**.
   Без этого шаг с `git push` упадёт.
5. Вкладка Actions → market-data → **Run workflow** — проверьте первый запуск вручную.
6. Убедитесь, что файл появился, и запомните ссылку:

```
https://raw.githubusercontent.com/<user>/<repo>/main/data/market_snapshot.json
```

Дальше эта ссылка вставляется в документ `claude/10_PROMPT_daily_brief.md` проекта.

## Тикеры

Списки в начале `fetch_market_data.py`: `RU_TICKERS`, `US_TICKERS`, `CRYPTO_SYMBOLS`.
Правьте под себя. Больше тикеров — дольше запуск, но 15 минут таймаута хватает с запасом.

## Источники

| Рынок | Источник | Ключ |
|---|---|---|
| Россия | T-Invest API, если задан секрет; иначе MOEX ISS | опционально |
| США | Stooq | не нужен |
| Крипто | Binance | не нужен |

Кроме T-Invest ключи не нужны нигде, и ни один источник не стоит денег.

## T-Invest как источник по России (необязательно)

MOEX ISS работает без ключа, но раннеры GitHub стоят вне России, и ISS теоретически может
их не пустить. Токен брокера снимает этот риск и даёт официальные данные.

**Токен никогда не вставляется в чат, в код и в репозиторий.** Единственное место —
GitHub Secrets: Settings → Secrets and variables → Actions → New repository secret,
имя `TINVEST_TOKEN`. Секреты доступны только раннеру, в логах маскируются, и в снимок
попадают только цены — не ключ.

Достаточно токена **только для чтения**. Выпускается в личном кабинете T-Инвестиций,
отзывается там же в один клик.

В workflow добавьте прокидывание секрета в шаг запуска:

```yaml
      - name: Fetch market data
        env:
          TINVEST_TOKEN: ${{ secrets.TINVEST_TOKEN }}
        run: python fetch_market_data.py
```

Без секрета скрипт молча работает на MOEX ISS — ничего настраивать не нужно.
Фактический источник записывается в снимок в поле `sources.RU`, так что вы всегда
видите, откуда пришли цифры.

Первый прогон с токеном проверьте по логу: скрипт печатает `Источник по России: ...`,
а при неверном токене падает с явным сообщением про HTTP 401/403. Скрипт пробует два
адреса API — `invest-public-api.tbank.ru` и старый `invest-public-api.tinkoff.ru` —
и запоминает тот, что ответил.

Незакрытая дневная свеча (`isComplete: false`) отбрасывается: она искажает индикаторы.

## Что проверить на первом запуске

- MOEX ISS обычно доступен с зарубежных адресов, но раннеры GitHub находятся вне России.
  Если в `failures` окажутся все российские тикеры — смените источник на секцию котировок
  брокера или запускайте сборщик на своей машине по расписанию.
- Stooq отдаёт дневные свечи с задержкой после закрытия сессии США. Для вечернего запуска
  это значит, что последняя свеча может быть за предыдущий день. Поле `last_date`
  в снимке показывает фактическую дату — ориентируйтесь на него, а не на дату запуска.

```json
{
  "generated_at_msk": "2026-08-26 08:00",
  "timeframe": "1D",
  "markets": {
    "RU": [{
      "ticker": "SBER", "exchange": "MOEX", "currency": "RUB",
      "last_close": 271.48, "last_date": "2026-08-25", "change_pct": 0.73,
      "sma20": 264.3, "sma50": 261.0, "sma200": 252.4, "ema20": 267.1,
      "rsi14": 55.08, "macd": 0.31, "macd_signal": 0.12, "macd_hist": 0.19,
      "atr14": 4.62, "volume": 41230000, "volume_avg20": 38100000,
      "high_20d": 276.2, "low_20d": 258.9, "high_52w": 322.0, "low_52w": 231.4,
      "position": "выше SMA20, выше SMA50, выше SMA200"
    }]
  },
  "failures": []
}
```

Недоступное значение — `null`, никогда не выдуманное число.
